# DriftCore

DriftCore enables high-throughput, scalable data processing on a flexible, cloud-based platform, featuring auto-scaling and real-time data streaming capabilities.

DriftCore is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DriftCore.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DriftCore, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
